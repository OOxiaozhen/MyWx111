# 图标资源目录

本目录用于存放图标相关的**源文件与设计资源**，当前界面使用的图标全部为
**代码矢量绘制**，不依赖本目录中的任何图片文件。

## 当前实现方式

- 图标源：`src/ui/IconFactory.cpp`（几何路径绘制）
- 对外接口：`src/ui/IconFactory.h` 中的 `IconFactory::GetIcon(IconId, size, color)`
- 使用方：任何界面代码只需 `#include "../ui/IconFactory.h"` 后调用该接口取图，
  无需关心图标如何绘制，也无需加载资源文件。

这样做的好处：静态链接 wxWidgets 时不依赖资源打包链路，不会因为图标文件缺失
而出现空白按钮。

## 图标规格（参考 KiCad 图标设计指南）

| 项目 | 规格 |
| --- | --- |
| 逻辑画布 | 24 x 24 px（所有路径按此坐标系书写，输出时整体等比缩放） |
| 主干线宽 | 2.0 px（传达主要含义的水平/垂直线） |
| 细节线宽 | 1.5 px（如放大镜内的「+」「−」） |
| 风格 | 纯色扁平，**禁止渐变、禁止阴影与 3D 光照效果** |
| 端点与转角 | 圆头圆角（等宽描边，避免手绘卡通观感） |
| 配色 | 默认单色深灰 `wxColour(60, 60, 60)`，由调用方传色，便于适配深色主题 |
| 细节程度 | 极简，24px 下不保留精细特征 |

## 新增一个图标的流程

1. 在 `IconFactory.h` 的 `IconId` 枚举中追加一个值，并写清中文文档注释。
2. 在 `IconFactory.cpp` 的匿名命名空间内新增一个绘制函数，
   签名形如 `void DrawXxxIcon(wxGraphicsContext& gc, const wxColour& color)`，
   坐标一律按 24x24 逻辑坐标系书写。
3. 在 `IconFactory::RenderIcon` 的 `switch` 分派中补上对应的 `case`。
4. 调用方直接用 `IconFactory::GetIcon(IconId::Xxx, FromDIP(18))` 取图即可。
   缓存按（图标、尺寸、颜色）自动生效，无需手工管理。

## 关于位图 / SVG 源文件

当前**未使用**任何 SVG 或 PNG 文件，本目录暂无图片资源。若将来需要改用
设计师产出的位图图标，可将 SVG 源文件放在本目录下，并在
`IconFactory::RenderIcon` 中替换为位图加载实现；届时需同时确认
资源在静态链接与发布目录下的查找路径。
